repasandoCSS

para instalar Tailwind:

se ejecuta en la carpeta del proyecto el comando:

	npm install tailwindcss @tailwindcss/vite

Luego se debe modificar el archivo "vite.config.ts" agregando las líneas que están entre doble asterisco (sin agregar los asteriscos) a continuación:

	import { defineConfig } from 'vite'
	**import tailwindcss from '@tailwindcss/vite'**
	export default defineConfig({
	  plugins: [
	    **tailwindcss(),**
	  ],
	})

luego en el archivo de la hoja de estilos (generalmente styles.css o main.css) se debe agregar el siguiente import:

	@import "tailwindcss";

Para más info consultar la siguiente liga:
	
https://tailwindcss.com/docs/installation/using-vite

Nota importante respecto al @apply de Tailwind:

Si se desea usar @apply (o @variant) en la etiqueta <style> de un componente Vue o dentro de módulos CSS, necesitarás importar las variables de tema, utilidades personalizadas y variantes personalizadas para que esos valores estén disponibles en ése contexto

para hacer eso sin duplicar ningún estilo CSS en la salida, se debe usar la directiva @reference para importar la hoja de estilos principal como referencia sin incluir realmente los estilos:

<style>
  @reference "../../app.css";

  h1 {
    @apply text-2xl font-bold text-red-500;
  }
</style>

Si solo está utilizando el tema predeterminado sin personalizaciones, puede importar "tailwindcss" directamente:

<style>
  @reference "tailwindcss";
  h1 {
    @apply text-2xl font-bold text-red-500;
  }
</style>

Para más información consultar:

https://tailwindcss.com/docs/functions-and-directives#reference-directive
